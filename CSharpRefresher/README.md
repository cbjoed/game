# C# Refresher

This project is a lightweight practice app to help you refresh your C# basics.

## Run it

From the project folder:

```bash
dotnet run
```

## What it covers

- variables and types
- strings and interpolation
- conditionals
- loops
- arrays and lists
- methods and classes
- dictionaries and LINQ-style processing
- simple challenge tasks

## Try these exercises

1. Change the sample values in each section.
2. Add your own method with parameters and return values.
3. Create another class to model something in your life.
4. Experiment with the `switch` statement and `List<T>`.
